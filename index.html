AppRaise

A free, web-based tool for quantifying evidence uncertainty in systematic reviews using a Bayesian mixture model.

What it does

Systematic reviews usually quantify random error well but describe study bias only in narrative terms, since primary studies rarely report bias as a number. AppRaise closes that gap: it lets reviewers express both random error and bias as probability distributions, then combines them across studies into a single posterior probability that a treatment effect exceeds a threshold the reviewer defines as clinically meaningful.

Rather than reporting an effect size with a confidence interval, AppRaise reports something decision-makers can act on directly: the probability that a treatment is beneficial, given the evidence and its known limitations.

Key features

  • Five bias types — confounding, selection bias, measurement error, model misspecification, and other bias, each modeled per study.
  • Five prior distribution families — Beta, Skew Normal, Laplace, Exponential, and Negative Exponential, so the shape of each bias can be tailored to the evidence.
  • Works with any effect measure — risk ratios, hazard ratios, odds ratios, mean differences, proportions, and more.
  • Study-specific weighting — reviewers can down-weight studies with more uncertain bias assumptions rather than treating all evidence as equally trustworthy.
  • Built on Stan/NUTS — samples the posterior using the No-U-Turn Sampler, pre-compiled so results typically return in a few seconds.

Validated against a real health technology assessment

Applied to an Ontario HTA on continuous glucose monitoring for type 1 diabetes, AppRaise produced an 86% posterior probability that continuous monitoring meaningfully reduces A1c compared with fingerstick testing — closely matching results from other established bias-adjustment methods, and offering a more decision-ready answer than the HTA's original qualitative GRADE rating of "moderate confidence."

Who it's for

Systematic reviewers, health technology assessment analysts, and evidence appraisers who want a quantitative, reproducible alternative — or complement — to qualitative bias scoring, without needing to write statistical code themselves.

Launch AppRaise

The app runs on demand, so the server may take a few seconds to wake up on first load. If you see a 502 error right after launching, just refresh the app page.
